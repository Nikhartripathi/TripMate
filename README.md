# ✈️ TripMate — AI Powered Travel Recommendation System

TripMate is an AI-powered travel recommendation web application that helps users discover destinations, generate smart itineraries, and plan trips efficiently.

## 🌟 Key Features

- AI-based travel destination recommendations
- Smart itinerary generation
- Interactive dashboard UI
- Modern glassmorphism design
- Fully responsive (mobile + desktop)
- Contact form using EmailJS

## 🧠 How It Works

TripMate analyzes user inputs like:

- Budget
- Travel interests
- Trip duration
- Preferred climate

Based on this, it recommends destinations and creates a smart itinerary.
